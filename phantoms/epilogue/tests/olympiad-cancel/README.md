# Отмена очереди Олимпиады Epilogue

Патч `0233-olympiad-cancel-atomic.patch` меняет только `Olympiad.unRegisterNoble`.
Подбор пары уже держит монитор `OlympiadManager` в `synchronized run`; отмена теперь использует тот же монитор.
Сначала проверяется назначенный матч, затем результат фактического удаления из очереди.
Уже выбранный в матч участник получает прежний штатный отказ; правило запрета его отмены сохранено.

## Что воспроизведено

- Пара удалена из очереди, но ещё не опубликована: старая отмена ошибочно отвечала «не зарегистрирован».
- Отмена проверила отсутствие матча, а затем подбор успел назначить классовую пару: старый код сообщал об успешном снятии, хотя игрок оставался в матче.
- На новом коде отмена либо успевает раньше подбора и исключает участие, либо видит назначенный матч и отказывает явно.

Тест вызывает реальные `unRegisterNoble` и `nextOpponents`, фиксирует ответы и управляет двумя порядками работы потоков.
Дополнительно проверены оба типа очереди, обе стороны матча, повторная отмена, чужой матч, отсутствие дворянства/периода и безопасная обработка пустых структур.
В конструктор игрового мира и базу не входит; Player — записывающий fixture, не персонаж живого сервера.

## Выполненные проверки

На установленной базе L2Hub 0.5.154: старый код — 8 проверок воспроизведения двух дефектов; новый — 80.
Отдельный нативный патч наложен штатными `parse_patch`/`apply_file` из builder.py, проверен обратный ход и точное сохранение байтов.
Его исходник отдельно скомпилирован против серверных библиотек; без локального Java-модуля повторены те же 80 проверок.
Локальный кандидат модуля прошёл 75 проверок совместимости; изменён один метод, остальные 340 классов и 456 ресурсов сохранены.

Сам файл `OlympiadCancelCheck.java` компилируется с Java 27 против библиотек собранного Epilogue.
Основной класс: `org.l2jmobius.gameserver.mechanics.olympiad.OlympiadCancelCheck`; на старом ядре аргумент `before`, на исправленном — без аргумента.
Это узкая изолированная проверка гонки, не новый прогонщик мира: общие проверки остаются в `tools/selftest_run.py epilogue`.

Не проверено: полный запуск нового upstream-дерева и поведение после установки в живом клиенте.
Рабочая игра не останавливалась; локальный пакет 1.3.19 только подготовлен, не установлен.
Рейты, цены, таймеры, награды и конфигурация не менялись.
