Forge of the Gods: два направления noblesse за адену

0507 добавляет верхний и нижний FoG в NOBLES_ADENA у Tatiana31275 (Goddard).
Координаты копируются из её же NOBLES_TOKEN; плата1000аден соответствует
остальным пунктам noblesse-списка. Оплата токеном13722×1 остаётся доступной,
обычный вход за10000не меняется. Это изменение доступности/стоимости двух
направлений, не исправление движка/геодаты и не новые телепорты всем персонажам.

Native TeleportHolder по-прежнему требует noble и выполняет обычные условия,
проверку/списание платы. Изменяется только XML: ни GM/боевые/осадные ограничения,
ни TeleportHolder, ни TeleporterData не переписываются. Имена сохранены как
у существующих направлений, чтобы штатная локализация работала одинаково.

Новые строки дописываются В КОНЕЦ NOBLES_ADENA. В Native ID — индекс внутри
списка; вставка перед старыми строками меняла бы их ID. Проверено на настоящем
Native parser: все42старыеlocationID/name/coords/feeId/feeCountостаютсяпрежними,
новые2получаютfeeId57поумолчанию/feeCount1000иnoblesse-группу.

Проверка данных: XSD teleporterData.xsd; Native TeleporterData.parseDocument
на изолированном контейнере с NoWorld/JDBCguard, без load()иобходавсегодатапака.
Ни doTeleport, ни World/SQL/клиент не вызываются. Patch штатного builder применён
и снят побайтно; других source-патчей к этому XML в базе нет.

После пересборки дерево данных должно содержать NORMAL14, NOBLES_TOKEN15,
NOBLES_ADENA15; два последних adena-пункта — верхний/нижний FoG. Реальное
появление меню, списание валюты и посадка персонажа в клиенте проверяются
отдельно. Рабочий ресурс не заменяется на запущенном сервере.
