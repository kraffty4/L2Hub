# История версий

Версия — `0.<готовых хроник из списка 1.0>.<порядковый номер коммита внутри этой цифры>`. 1.0 — все семь хроник списка: Interlude, High Five, Gracia Epilogue, Gracia Final, C4, Classic, Essence. Хроника считается готовой, когда она играбельна из L2Hub и в ней есть наши моды, которые технически можно перенести. Схема и список — `docs/PLAN.md` (раздел «Решения», 2026-10-18), статистика — `docs/CHRONICLES.md`. У каждой версии есть git-тег `vX.Y.Z`.
