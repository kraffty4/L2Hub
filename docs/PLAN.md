# План L2Hub

Создан 2026-10-16.

## Запрос автора

> можем ли мы сделать своё такое приложение? чтобы можно было побегать одному или с друзьями. чтобы было так же удобно, только плюсом выбор хроник игры

> я бы побегал в старые хроники, и новые тоже. последнее что я пробовал была годдесс оф дестракшн

> Хроники: все

> друзья: один в России, другой в Японии

Цель: удобство La2offline (одна кнопка — и играешь) плюс выбор хроники, кастомизация сервера и игра с друзьями по интернету. Проект личный.

## Архитектура

```text
Лаунчер
├── профиль хроники      profiles/<id>.json
│   ├── тип              mobius | la2offline
│   ├── сервер           servers/<id>/
│   ├── база             своя база в общей MariaDB
│   ├── клиент           путь к папке клиента
│   └── настройки        поверх конфигов сервера
├── runtime/jdk, runtime/mariadb   портативные, без установки в систему
└── data/mariadb, data/backups/<id>/
```

**«Играть»** для профиля Mobius:

1. Поднять MariaDB, если не запущена, дождаться порта.
2. Если базы профиля нет — создать и залить SQL из установщика базы сборки.
3. Применить настройки профиля к конфигам сервера.
4. Запустить логин-сервер, дождаться порта.
5. Запустить гейм-сервер, дождаться регистрации на логине.
6. Прописать адрес сервера в систему клиента (способ зависит от эпохи клиента).
7. Запустить клиент.

**«Стоп»** — корректно погасить гейм и логин (чтобы сохранились персонажи), затем базу. Бэкап базы профиля — дампом в `data/backups/<id>/`.

**Профиль Gracia Final** — копия La2offline в `servers/`, запуск его собственной MySQL и серверов. Как именно их стартует `La2offline.exe`, предстоит выяснить.

**Настройки** хранятся в профиле как набор переопределений и накладываются на конфиги при старте. Так они переживают обновление сборки Mobius. Оригинальные конфиги сборки не теряются.

**Режим «с друзьями»:** хост — ПК автора. друзья (Россия и Япония) подключаются через mesh-VPN (кандидаты: Tailscale, ZeroTier, Radmin VPN; доступность в России и Японии проверить вместе с друзьями). Запасной вариант — проброс портов логина и гейма на роутере, если есть белый IP. Лаунчер выставляет адрес хоста в `ipconfig.xml` и собирает друзьям пакет: система клиента под адрес хоста и короткая инструкция. Клиент той же хроники каждый ставит себе сам. Пинг до Японии проверить на практике.

**Стек лаунчера** — выбран 2026-10-17: Python 3.12 + pywebview (окно WebView2, интерфейс на HTML/CSS/JS из макета v2) + psutil; uv-проект `launcher/`. Python 3.12, а не 3.14 — из-за `pythonnet`. Рассматривались варианты:

- Python + PySide6 — ставится через `uv` без установки в систему, надёжно управляет процессами, упаковывается в exe;
- C# + WPF — родной для Windows, но нужен .NET SDK;
- Godot — автор его знает и можно сделать красивый интерфейс, но управление процессами и файлами там слабее.

## Окружение для фазы 1

Ставит автор. Всё — ZIP-архивами в `runtime/`, без установщиков, без служб и без PATH: лаунчер и скрипты будут вызывать их по полному пути.

| Что | Откуда | Куда |
|---|---|---|
| JDK 27, Eclipse Temurin, Windows x64, ZIP | adoptium.net | `runtime/jdk-27/` (внутри сразу `bin/java.exe`) |
| Apache Ant 1.10.x, binary ZIP | ant.apache.org | `runtime/ant/` (внутри `bin/ant.bat`) |
| MariaDB, свежий LTS, Windows x64, ZIP | mariadb.org | `runtime/mariadb/` (внутри `bin/mariadbd.exe`) |
| Клиент первой хроники и система для приватных серверов | ищет автор | путь — в профиль; место — открытый вопрос 3 |

Установлено 2026-10-16: Temurin 27+35, Ant 1.10.18, MariaDB 13.0.2.

Раскладка сервера Mobius: исходники — `servers/<id>/<папка Mobius>/`, Ant пишет результат в `servers/<id>/build/` (`build.xml` задаёт `../build`), итог — `servers/<id>/build/<папка Mobius>.zip` с `game`, `login`, `libs` и `db_installer`. Архив исходников остаётся в `downloads/`.

## Риски

- **Клиенты — главный риск.** Их надо искать самому, они большие, и новым клиентам для подключения к своему серверу нужна пропатченная система или свой способ запуска. У каждой эпохи клиента он свой.
- **Системы приватных серверов** — чужие защиты (Strix, SmartGuard и подобные), драйверы ядра, перехват сети и привязка к адресу их сервера. Для L2Hub нужны чистые системы без защиты; каждую перед запуском осматривать.
- **Место.** Все хроники сразу на C: не влезут. Нужна схема «активные на быстром диске, остальные в архиве на E:».
- **Goddess of Destruction** у Mobius нет. Нормального бесплатного эмулятора может не найтись.
- **Требования Mobius к Java растут:** снапшот 2025-07 требовал JDK 24, `master` на 2026-10-16 — уже JDK 27. Версию брать из `build.xml` конкретной сборки, а не держать одну на всех.
- **Сеть до Японии** — задержка и стабильность VPN.

- 2026-10-23 — рейды на эпиков (автор, `docs/PHANTOMS.md`, 4.43):
  - эпик — только с живым игроком: охотники собираются и зовут его (крик, `.raid`), без него эпика не бьют — иначе охотники заберут эпиков себе;
  - «Эпики малого мира» ослабляют самого эпика для всех (HP, число нянек и гвардии), а не дают охотникам множители: тогда и урон игрока что-то решает;
  - рейд проваливается, только когда легли все, а не лидер: лидерство переходит;
  - хилеры держат танка и лидера;
  - под каждого эпика — свой рецепт боя. Автор на эпиков не ходил, рецепты собирает агент: скрипты боссов Mobius и гайды;
  - «измор»: после неудачного рейда эпик N минут не регенит, несколько заходов подряд его изматывают.
