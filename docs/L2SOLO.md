# L2Solo — хроника C4 в L2Hub

[L2Solo](https://github.com/pmbstyle/L2Solo) — свой эмулятор C4 Scions of Destiny (протокол 656) на Node.js, Apache-2.0, публичная альфа. Это сильно переделанный форк [NodeL2](https://github.com/NodeL2/NodeL2), рассчитанный на одного живого игрока. Боты — до 1700: «горячие» рядом с игроком, «холодные» в фоне. Боты сами качаются, торгуют, собирают кланы и пати. По желанию к ним подключается LLM через любой OpenAI-совместимый API. База — встроенная SQLite, MariaDB и Java не нужны. Авторы пушат почти каждый день. Разбор их ботов и того, что мы взяли в High Five, — `docs/PHANTOMS.md`, раздел 1.2.

Решение автора (2026-10-20): C4 не собираем на Mobius, а берём L2Solo как есть. Их код не патчим и в наш репозиторий не кладём, мы его только запускаем. Обновление — `git pull` у авторов и `npm install`.

## Как устроено в L2Hub

Профиль — `profiles/c4.json`, тип `l2solo`. Код — `launcher/l2hub/l2solo.py`, их код на Node зовёт `launcher/l2hub/l2solo_tool.js` (сохранения, вайп, проверка LLM), экраны «Мой мир» — `launcher/l2hub/ui/l2solo.js`. В общих модулях (`servers.py`, `health.py`, `backups.py`, `api.py`, `ui/app.js`) — только развилки «если L2Solo — туда».

- **Запуск.** Лаунчер запускает `node scripts/run-server.js` в папке `servers/c4` — ту же обёртку, что их веб-лаунчер (`npm start`). Обёртка проверяет геодату и поднимает `src/NodeL2`. Логин (2106) и гейм (7777) — один процесс: в окне обе плитки показывают один PID. Сервер работает в скрытой консоли, PID обёртки лежит в `data/run/c4.json` под ключом `server`. Пустой мир поднимается секунд за десять. Перед каждым запуском лаунчер снимает сохранение мира.
- **Лог.** Своего лога у L2Solo нет, только вывод в консоль. Лаунчер пишет его в `servers/c4/tmp/logs/l2hub-c4.log`, прошлый запуск — в `l2hub-c4.previous.log`. Время «ЧЧ:ММ:СС» в начале строк ставит наш прелоад `launcher/l2hub/l2solo_logtime.js` (`NODE_OPTIONS=--require`, только процессу сервера, с 2026-10-21). В конце лога лаунчер ставит отметку остановки: «штатно, мир сохранён» или «жёстко».
- **Остановка.** Лаунчер шлёт Ctrl+C в консоль сервера. Обёртка и сервер ловят SIGINT, сервер сбрасывает буфер персонажей, гасит воркеры и закрывает SQLite (`shutdown` в `src/NodeL2.js`). Через 15 с сервер выходит сам, обёртку лаунчер ждёт до 60 с. Остановка считается штатной, если в логе есть `flushing buffered character state` и нет ошибок слива. Если сервер не вышел сам, лаунчер убивает всё дерево процессов и показывает ошибку: последние минуты могли не сохраниться. «Аварийная остановка» в меню тоже убивает всё дерево (обёртку и NodeL2).
- **Настройки.** Наш слой — `data/l2solo/c4.ini`. Лаунчер пишет его из профиля при каждом запуске: логин и гейм слушают `127.0.0.1` (у L2Solo по умолчанию — все сети), порты, веб-карта, LLM. Сервер читает слой через `L2NODE_SHARED_CONFIG_FILE`: порядок слоёв — `config/default.ini` (их, из git), наш слой, `config/local.ini` (их файл для личных правок, в git у них не входит). Правки автора в `local.ini` главнее слоя. Свои ключи в слой можно добавить разделом `"config"` профиля: `{"BotPopulation": {"pvpAggression": 0.3}}`. «Настройки» в окне для C4 открывают папку `servers/c4/config`: их ini из окна не правим.
- **Рейты.** Пресет `x1`, `x10` или `x50`: умолчание — `"progression"` в профиле, выбор из пульта — в `data/l2solo/c4.settings.json` (в git не входит). Лаунчер передаёт его переменной `L2NODE_PROGRESSION_RATE`, как их веб-лаунчер.
- **База.** Мир — `servers/c4/tmp/nodel2.sqlite`, история рынка, кланов и PvP — `tmp/nodel2.history.sqlite`. Блокировку держит `nodel2.sqlite.access.sqlite`: пока сервер работает, их сохранения и вайпы базу не трогают. Лаунчер читает мир только на чтение (онлайн, ботов, персонажей). Аккаунты ботов — `bot_*`, всё остальное — игроки.
- **Сохранения (бэкапы).** «Сервис» → «Бэкапы базы» для C4 показывает их Saved Games из `servers/c4/tmp/saves`: каждое — полная копия мира и истории с контрольными суммами. Делает их их же код: `l2solo_tool.js` вызывает `scripts/saved-games.js`. Поэтому сохранения видны и в их веб-лаунчере, а загрузка идёт их проверкой целостности и пары «мир + история». Снять сохранение можно только у выключенного сервера, так у них устроено. Метки лаунчера — в имени: `L2Hub: start`, `L2Hub: manual`, `L2Hub: before-restore`, `L2Hub: before-wipe`; сохранения, сделанные в их лаунчере, видны под своими именами. Авто-сохранений «перед запуском» хранится 3 (`l2solo.KEEP_AUTO`): это полные копии мира, старые уходят в Корзину. Откат сначала сохраняет текущий мир с меткой «перед откатом». Журнал — `data/backups/db/c4/backups.log`.
- **Персонажи.** «Сервис» показывает персонажей игроков без ботов, только на чтение. Права GM не нужны: админка `.admin` в L2Solo открыта всем.
- **Не подключено.** Режим друзей (разбор и капканы — раздел «Режим друзей»), «Только база» (база встроена в сервер).
- **Веб-карта мира** их WorldObserver — `http://127.0.0.1:8088/observer/`, пока сервер работает; в окне — «Мой мир» → «Карта мира» (раздел «Пульт L2Solo в L2Hub»).

Проверка ядра без окна (из `launcher\`):

```
.venv\Scripts\python -m l2hub.cli state c4
.venv\Scripts\python -m l2hub.cli check c4
.venv\Scripts\python -m l2hub.cli start c4 --no-client
.venv\Scripts\python -m l2hub.cli stop c4
```

Сервер, поднятый из консоли агента, умирает при обновлении приложения Claude (AGENTS.md). Из консоли — только проверки, для игры сервер запускает автор из окна.

Проверено 2026-10-20 на запасных портах (12106, 17777, 18088), тестовой базе в scratchpad и 60 ботах, без клиента: старт за 7–16 с, состояние, онлайн и боты из базы, «Проверить всё». Через `Api`, как окно: Играть с авто-сохранением, перезапуск, Стоп. Штатная остановка — «flushing buffered character state before SIGINT», все процессы node вышли. Сохранение, откат с сохранением «перед откатом», аварийная остановка всего дерева. Окно — через дев-сервер: плитки, «Проверить всё», «Сервис», «Друзья», «Мой мир».

Каждый пробный connect к порту L2Solo пишет в лог как `ECONNRESET`. Поэтому лаунчер смотрит порты всех хроник по таблице соединений, без подключения (`servers.listeners`, с 0.2.23). Адреса в «Проверить всё» и в плитках — из сокетов самого сервера: их держит дочерний NodeL2, а не обёртка.

## Установка с нуля

Из корня L2Hub:

```
git clone https://github.com/pmbstyle/L2Solo.git servers/c4
cd servers/c4
npm install --ignore-scripts
npm run geodata
```

Затем клиент (раздел «Клиент») и `profiles/c4.json`.

### Установка из окна (бэкенд, 2026-10-21)

Для мастера «Установить» (решение автора 2026-10-21: установка из окна — для любой хроники с сервером). Ветку `server == "l2solo"` в `Api.install_plan` / `Api.install` и экран делает оболочка; бэкенд — в `l2solo.py`:

- `l2solo.pin()` — `launcher/l2hub/l2solo_pin.json`: закреплённый коммит L2Solo (`d132ed63`, 2026-10-18, ветка `main`), примерные размеры, их клиент и client mod (ссылки на их Google Drive из README, файлы, размеры, SHA-256) и отпечаток `L2.exe` их репака. Сменить коммит — только проверив, что L2Solo на нём стартует и оверлей покрывает фразы.
- `l2solo.install_plan(template)` — шаблон профиля (`profiles/c4.json` программы) → `{"ok", "build", "mods", "steps": [строки], "download": байты, "client": client_sources()}`. Уже сделанное в шаги не входит.
- `l2solo.install_steps(template, out=print)` — `[(текст этапа, функция)]` для `Api._start_job`; каждый шаг пропускает сделанное, прерванную установку можно повторить:
  1. Node.js — `runtimes.install("node")` (`runtimes.json`: официальный ZIP 24.19.0 с nodejs.org, SHA-256), только если нет подходящего (профиль, `runtime\node`, системный ≥ 22.15). `runtimes.status()` по умолчанию — только рантаймы Mobius, Node — `status("l2solo")` (поле `only`);
  2. код — `git clone` ветки `main` и `reset --hard` на закреплённый коммит (обновления из окна потом работают), без git — архив GitHub по SHA со сверкой коммита в комментарии zip (обновлять из окна тогда нельзя, план так и пишет);
  3. `npm install --ignore-scripts` — Node установки первым в `PATH`;
  4. геодата — их `scripts/ensure-geodata.js` (их сверка SHA-256), до 203 регионов;
  5. профиль `profiles/c4.json` в папке данных — `l2solo.install_profile(template)`: клиент пустой, LLM выключен, если ключа `data/brain/<keyFile>` нет.
- `l2solo.client_sources()` — где взять клиент и мод: `{"client": {title, url, file, size, sha256}, "mod": {...}}`. Не раздаём: пользователь качает сам по их ссылкам.
- `l2solo.client_check(folder)` — папка клиента (можно сам клиент или его `system`): `{"ok", "path", "exe", "l2solo": клиент их репака, "mod": стоит client mod, "warn"}` или `{"ok": false, "error", "where"}`. Не их клиент или нет мода — предупреждение, играть можно. Записать папку в профиль — общий `Api.set_client_path`.
- Пока клиент не указан, «Проверить всё» пишет «Клиент: папка клиента не указана» с подсказкой (раньше — красное «нет L2.ini»).

Проверено 2026-10-21 на пустой папке данных `L2HUB_HOME=<рабочая папка>\L2Hub_c4test`: план → шаги за 41 с (git clone 11 с, npm 24 с, геодата 6 с), профиль с пустым клиентом и выключенным LLM, `install_problem` — пусто, обновление видит ветку `main` без отставания; Node с nodejs.org отдельно — SHA сошлась, 24.19.0. Живой старт из этой папки — 18 с, порты на 127.0.0.1, остановка штатная. Путь без git — в `<рабочая папка>\L2Hub_c4test2`: архив 24 МБ, коммит сверен. `client_check`: клиент L2Solo — `l2solo: true, mod: true`; клиент Interlude — с предупреждением; пустая папка — ошибка с «где взять».

## Обновление

Из лаунчера (с 2026-10-21): `Api.l2solo_update_check` — `git fetch` и список новых коммитов авторов; `Api.l2solo_update` — задача у выключенного сервера, шаги в `l2solo.update_steps`:

1. проверка: сервер выключен, в их файлах нет правок (`git status`), нет наших коммитов поверх `origin/main`, код не откачен на старый коммит;
2. сохранение мира с меткой «перед обновлением» (`before-update`);
3. `git pull --ff-only`;
4. `npm install --ignore-scripts` — только если поменялись `package.json` или `package-lock.json` (или нет `node_modules`).

Журнал — `data/l2solo/c4.update.log`: время, коммит «было → стало», сколько коммитов, ставился ли npm, id сохранения. В окне — пульт C4, карточка «Код L2Solo» (0.4.23). Руками — то же самое:

```
cd servers/c4
git pull
npm install --ignore-scripts
```

Перед ручным обновлением — сохранение мира («Сервис» → «Сделать бэкап» у выключенного сервера). При старте L2Solo сам мигрирует базу (`schema_migrations`), и старый код новую базу может не открыть. Откат кода: прежний коммит — в журнале обновлений или `git -C servers/c4 log`; `git -C servers/c4 checkout <коммит>`, `npm install --ignore-scripts`, затем загрузить сохранение «перед обновлением». Вернуться на свежий код — `git -C servers/c4 checkout main` (пока код откачен, обновление из лаунчера откажет и подскажет это). Ветка у L2Solo — `main`, авторы обновляют её релизами из `develop`; на 2026-10-21 новее `d132ed63` (2026-10-18) ничего нет.

Проверено 2026-10-21 на локальном клоне, откаченном назад: проверка видит отставание, перемотка до `d132ed63`, npm пропущен (файлы пакетов не менялись), строка в журнале.

## Клиент

L2Solo понимает только клиент C4 протокола 656. Клиент C5, скачанный автором (`<загрузки>\Lineage II Chronicle 5 - Oath of Blood.zip`), не подойдёт. Нужен их клиент с Google Drive.

Осмотр 2026-10-20, без запуска, по образцу систем H5 (`docs/PLAN.md`, фаза 1):

- Клиент — репак La2base.ru 2014 года (`system\GameGuard\comments.txt`). Почти все файлы — оригинал NCSoft 2005–2006 годов. `L2.exe`, `Core.dll` и `NWindow.dll` пересохранены 2014-12-14, `.dat` и `l2.ini` перешифрованы 2023-04-01 ключом комьюнити. Подписей у бинарников NCSoft нет.
- `l2.ini` (расшифровка — `tools/l2ini_decode.py`): `ServerAddr=127.0.0.1`, `Port=7777`, `Language=0`.
- `system\dsetup.dll` (2022-03-13) — не DirectX, а «Lineage II Loader» от Akumu. Подпись EV-сертификатом Eikonect Software SL (Испания, DigiCert) действительна. Импорт — только `kernel32`. По строкам он находит в `engine.dll` флаги `GL2UseGameGuard`, `GIsGuarded`, `GL2UseNCGuard` и `FL2ReplayManager::PrepareLoad` — так в репаках выключают GameGuard. `L2.exe` грузит его вместо DirectX-сетапа.
- `system\GameGuard\` — штатные файлы GameGuard 2005 года. Их запускает только `L2.exe` с включённой защитой, а лоадер её выключает. `npkcrypt.sys` и `npkcusb.sys` — 32-битные драйверы nProtect: на x64 Windows не загружаются, как и в системе H5.
- Сетевые импорты (`wsock32`, у `NWindow.dll` ещё `wininet` и `ws2_32`) — как в оригинале. Чужих адресов и защит (Strix, SmartGuard и подобных), перехватчиков сети, `.bat`, `.ps1` и `.vbs` в клиенте нет.
- Client mod: `system\C4Chat.dll` (2026-10-14, x86, без подписи, импорт только `kernel32` и `user32`, экспорт `C4ChatInitialize`) — новое окно чата. `system\NWindow.dll` — оригинал 2006 года с добавленной секцией `.chatld` и импортом `c4chat.dll`, так он и подгружает мод. Ещё шрифты чата (`ChatFont12–20.gly`, `.utx`), `C4Chat.ini` (ширина и размер шрифта), текстура `C4Dock.utx`. `user.ini` отличается от клиентского одной строкой: `MaxZoomingDist` 250 → 65535 (камера отъезжает дальше). `Start-L2.cmd` и `Start-L2.ps1` пишут в `Option.ini` три ключа `[Video]`, запускают `L2.exe` и убирают рамку окна. В сеть не ходят.
- Defender (`MpCmdRun -Scan -ScanType 3`, без лечения): угроз нет — в архивах, в `system` клиента и в моде.

Итог: защит и сетевых перехватчиков нет. Из чужого кода — лоадер Akumu (выключает GameGuard) и мод чата L2Solo. Автор дал «да» 2026-10-20.

Проверено 2026-10-20, без сервера: клиент из лаунчера (`servers.start_client`) за 2,5 с открывает окно `L2UnrealWWindowsViewportWindow` 1280×800 (`Option.ini`: `StartupFullScreen=False`) и доходит до экрана логина. В процессе загружены `dsetup.dll` (лоадер), `NWindow.dll` и `c4chat.dll` (мод: «C4Chat initialized», «Chat created» в `system\C4Chat.log`). Дочерних процессов и GameGuard нет, сетевых соединений до нажатия «Log In» нет. «Закрыть клиент» его гасит, PID из `data/run/c4.json` убирается. Вход в мир — за автором.

Установлено 2026-10-20: распакованный клиент перенесён в `<игры>\Lineage2-C4` (тот же диск — просто перенос папки), 1345 файлов, 4,8 ГБ. Мод — поверх: оригиналы `system\NWindow.dll` и `system\user.ini` остаются рядом как `*.orig`, `Start-L2.cmd` и `Start-L2.ps1` — в корень клиента. Лаунчер запускает `system\L2.exe` напрямую, как у других хроник, так что безрамочного окна из `Start-L2` нет. Откат мода — вернуть `*.orig` и убрать файлы мода по списку из архива.

## LLM ботов

У L2Solo LLM — любой OpenAI-совместимый Chat Completions. Ключ DeepSeek автора (`data/brain/deepseek.key`) подключён с согласия автора 2026-10-20 — раздел `"llm"` в `profiles/c4.json`:

```json
"llm": { "enabled": true, "apiUrl": "https://api.deepseek.com/chat/completions", "model": "deepseek-flash", "keyFile": "deepseek.key" }
```

Лаунчер напишет в слой секцию `[AI]` (адрес, модель, `partyRouterModel` — по умолчанию та же модель, доп. ключи — `"options"`). Ключ передаётся переменной `L2NODE_AI_API_KEY` при запуске, в файлы не пишется и не печатается. Без раздела `"llm"` боты говорят заготовками, без запросов к модели. С `reasoningEffort = off` (их умолчание для `[AI]`) L2Solo шлёт `reasoning_effort: "none"`, а наш `brain.py` выключает размышления DeepSeek параметром `thinking`. Проверено 2026-10-20: DeepSeek принимает оба варианта (HTTP 200, размышлений 0). Один запрос их шлюзом (`OpenRouterGateway.request`) с нашим слоем и ключом из переменной — ответ за 1,5 с, 45 → 30 токенов. Таймаут у них зашит — 3,5 с, ответ до 320 токенов, JSON-схемы для `[AI]` выключены (`strictSchema = false`).

Расход. Лимиты зашиты в `src/GameServer/Bot/AI/BotInferenceBudget.js`: на бота — 6 запросов в минуту, на всех — 240 запросов, 300 тыс. токенов на вход и 64 тыс. на выход в минуту. По тарифу DeepSeek (`deepseek-flash`: $0,30 и $1,20 за 1 млн) потолок — около $0,17 в минуту, это худший случай. Обычно модель зовут, когда игрок говорит с ботами (чат, пати, клан). Без игрока модель тоже работает: кланы ботов пересматривают цели раз в 5 минут (`[ClanSimulation] llmGoalManagementEnabled`). Учёт расхода (с 2026-10-21): прелоад `launcher/l2hub/l2solo_usage.js` (только серверу и только с включённым LLM) берёт `usage` из ответов модели их шлюзу и раз в 30 с и при остановке пишет в `data/l2solo/c4.usage.json` — формат как у `data/brain/usage.json`, ключ `l2solo:<модель>`. Отдельный файл, а не общий: средние токенов по мозгам охотников (`api._tokens_per_request`) не смешиваются с болтовнёй L2Solo. Сводка — `l2solo.llm_usage`: сегодня, 7 дней, всё, цена по ценам из настроек мозгов (`data/brain/settings.json`, сейчас $0,30 и $1,20 за 1 млн); видна в «Проверить всё» («LLM ботов: … запросов сегодня N, за 7 дней M, $X») и в `panel().llm.usage` для пульта. Проверено 2026-10-21 запросом их шлюзом: 1 запрос, 35 и 16 токенов в файле. Выключить — переключатель в «Мой мир» → «Пульт» (выбор — в `data/l2solo/c4.settings.json`, поверх профиля), насовсем — `"enabled": false` в разделе `"llm"` или убрать раздел. Если нужен L2Solo без нашего слоя (`npm start`, их веб-лаунчер) — их настройки LLM лежат в `config/local.ini`.

## Пульт L2Solo в L2Hub

У L2Solo два своих пульта: веб-лаунчер (`npm start`, `http://127.0.0.1:8090`) и карта мира WorldObserver (`:8088/observer/`). В L2Hub они сведены в «Мой мир» → Scions of Destiny (2026-10-20, просьба автора). Точку встройки для миров со своим интерфейсом (`window.worldKinds`, `ui/world.js`) сделала сессия оболочки, экраны — `ui/l2solo.js`, ядро — `Api.l2solo_*` и `l2solo.py`.

- **Карта мира** — их WorldObserver во фрейме, пока сервер работает: карта с ботами и игроками, пати, кланы и их заказы, рейтинги, рейд-боссы, рынок, база предметов и NPC. Интерфейс — их, по-английски. «Открыть в браузере» — то же в браузере по умолчанию, там просторнее. Сервер выключен — заглушка с «Запустить мир без клиента».
- **Пульт:**
  - режим сервера (0.4.110): «Хардкор» / «PvP-крафт» / «PvP» — пресет рейтов, злость мира, квесты и заточка разом; таблица — `launcher/l2hub/l2solo_modes.json` (как `server_modes.json` у Mobius, но на ключах L2Solo), активный узнаётся по значениям, иначе — «свои настройки». «Хардкор» — ровно L2Solo (x1, их заточка и боты), PvP-крафт и PvP — предложение агента;
  - рейты x1 / x10 / x50; если сервер работает на других — кнопка перезапуска;
  - злость мира (0.4.110): мирный / как есть / злой — `[BotPopulation] pvpAggression` 0 / 0.5 / 1; награды квестов x1 / x2 / x3 / x5 — `[General] questRewardRate` (множится на пресет); заточка полями — `[Enchant]`: шансы обычных, благословлённых и кристальных свитков, безопасная (`safeMax`, `safeMaxFull`), потолки; «Как у L2Solo» — сбросить. Всё — ключами слоя (`l2solo.TUNING`, выбор — `world` в `data/l2solo/<id>.settings.json`); значение, равное профилю или их `default.ini`, в слой не пишется. Ключ из их `config/local.ini` главнее слоя — пульт так и подписывает;
  - «настройки поменялись после запуска» (0.4.110): копия слоя на старте — `data/l2solo/<id>.live.ini`; разошлась с выбором в пульте (режим, ручки, болтовня, LLM) — подсказка и кнопка перезапуска;
  - команды L2Solo (0.4.110): карточка-шпаргалка — пати с ботами, слова спутникам, `.buff`, `.sell`, AFK-лавка, `.go`, `.admin`;
  - LLM ботов вкл/выкл и «Проверить связь» — один запрос их шлюзом с нашим слоем и ключом;
  - мир: игроки, боты, размер базы;
  - вайп: боты / игроки / весь мир — их кодом (`scripts/world-wipe.js`), только у выключенного сервера, после подтверждения с числом персонажей и аккаунтов. Перед вайпом лаунчер снимает сохранение «перед вайпом», откат — в «Сервисе».
- Остальное их веб-лаунчера в L2Hub уже есть: старт и стоп, сохранения, лог. Их веб-лаунчер параллельно с L2Hub не запускать: он сам стартует тот же сервер на тех же портах.

Проверено 2026-10-20: пульт через `Api` на тестовом профиле (запасные порты, тестовая база) — рейты (x10 подхватился при старте, при работающем сервере — «нужен перезапуск»), проверка LLM (ответ за 1,3–1,6 с), предпросмотр и вайп ботов с сохранением перед ним, отказы без подтверждения и при работающем сервере; в окне через дев-сервер — список миров, «Карта мира» (заглушка и сама карта во фрейме), «Пульт», «Проверить связь».

## Язык и болтовня ботов

Отзыв автора после первой игры (2026-10-20): боты пишут по-английски, а в чате флудильня.

**Язык.** Своей настройки языка у L2Solo нет. Английский идёт из двух источников:

- Фоновая болтовня без LLM — крик в глобальный чат, LFP/LFG, WTS/WTB, тревога о ПК, реакции, сценки в белом чате — собирается из шаблонов `src/GameServer/Bot/AI/BotSpeechTemplates.js`: 94 ключа, около 900 английских фраз прямо в коде. Модуль экспортирует свой словарь (`catalog`, `voices`) как изменяемый объект.
- Ответы LLM. Живой разговор с игроком идёт «на языке игрока» (`BotDialogueStyle.js`): напишешь боту по-русски — DeepSeek ответит по-русски. Исключения прошиты в промптах: торговец отвечает только по-английски (`BotBrain.js`, `englishOnly`), клановый чат и титулы кланов — «in English» (`ClanDialogueService.js`, `ClanTitleBrain.js`).

**Что клиент C4 умеет показать** (разбор шрифтов 2026-10-21, без запуска клиента). Шрифт `.gly` — таблица прямоугольников глифов по диапазонам Юникода, атлас — текстура в `.utx`:

- Чат мода (`system/ChatFont12–20.gly`, `systextures/ChatFont*.utx`, атлас 1024×256 DXT3) — три диапазона: U+0020–00FF (латиница), **U+0400–04FF (кириллица: А–я, Ё, ё и прочее)** и U+2010–202F (тире, кавычки). Русский текст от сервера в чате мода виден.
- Родной шрифт клиента (`SmallFont-e.gly`, `LargeFont-e.gly`: язык `English` в `localization.ini`, Lineage2Ver111) — только U+0020–007E. Всё, что рисует сам клиент — ники, титулы, названия кланов, надписи лавок, окна NPC, системные сообщения вне чата, — кириллицу не покажет. Поэтому там остаётся латиница, и оверлей это знает.
- Ввод: поле ввода рисуется родным шрифтом, поэтому набранная кириллица может быть просто не видна, а уйти на сервер нормально. Строки «кириллица не набирается» мало — нужна проверка в игре (ниже).

Лист глифов любого незашифрованного шрифта — `python -X utf8 tools/l2_font_glyphs.py <шрифт.utx> <шрифт.gly> <лист.png>` (формат `.gly` — в описании скрипта).

**Болтовня.** Частоты читаются из `[BotPopulation]`, и наш слой их перекрывает: профиль, раздел `"config"`. С 2026-10-20 они снижены примерно в 3–5 раз, ориентир «живо, но не флудильня»:

| Ключ | У L2Solo | У нас | Что это |
|---|---|---|---|
| `globalChatMinIntervalMs` | 18000 | 90000 | общий бюджет крика в глобальный чат, вместе с ответами |
| `globalChatTopicIntervalMs` | 120000 | 600000 | одна тема — не чаще |
| `globalChatChance` | 0.015 | 0.006 | шанс, что холодный бот заговорит |
| `chatReactionChance` | 0.45 | 0.2 | шанс ответить на чужую реплику |
| `marketTradeChatIntervalMs` | 480000 | 1200000 | WTS/WTB одного бота |
| `marketTradeChatGlobalMinIntervalMs` | 100000 | 300000 | WTS/WTB на весь мир |
| `partyRecruitmentChatIntervalMs` | 720000 | 1800000 | LFP одной пати |
| `partyRecruitmentChatGlobalMinIntervalMs` | 90000 | 300000 | LFP на весь мир |
| `clanChatMinIntervalMs` | 15000 | 60000 | клановый чат |
| `ambientSceneCooldownMs` | 180000 | 600000 | сценки ботов рядом с игроком в белом чате |
| `ambientPairCooldownMs` | 90000 | 300000 | одна пара ботов — не чаще |

Выключить канал целиком — `globalChatEnabled`, `marketTradeChatEnabled`, `partyRecruitmentChatEnabled`, `clanChatEnabled`, `chatReactionsEnabled`, `ambientScenesEnabled` = `false`. Пресеты болтовни (с 0.4.27, `l2solo.set_chatter`, `Api.l2solo_set_chatter`, выбор — в `data/l2solo/c4.settings.json`): `off` — все эти каналы выключены, боты только отвечают игроку; `quiet` — интервалы ×2 и шансы ×0,5 от профиля; `normal` (по умолчанию) — как в профиле; `l2solo` — без наших частот, как в их `default.ini`. Применяется при следующем запуске; видно в «Проверить всё» («Болтовня ботов») и в `panel().chatter`. Тишина вокруг игрока после непрошеной реплики (`BotChatterBudget.js`: 45 с на округу, 120 с на говорящего, 5 минут на тему) зашита в код. Проверено 2026-10-20: сервер с нашим слоем видит все значения (`PopulationConfig`), стартует и гасится штатно. Как это ощущается в игре, покажет следующий заход автора.

**Русский оверлей** (сделан 2026-10-21, по умолчанию выключен; включить — «Язык ботов» в пульте C4 (0.4.23), `"botLanguage": "ru"` в `profiles/c4.json` или `Api.l2solo_set_language("c4", "ru")` — выбор ляжет в `data/l2solo/c4.settings.json`; применяется при следующем запуске сервера). Их файлы не меняются: лаунчер добавляет в `NODE_OPTIONS` `--require launcher/l2hub/l2solo_ru.js`, прелоад попадает в обёртку, сервер и воркеры (холодные боты) и подменяет в памяти:

1. фразы каталога `BotSpeechTemplates` (`catalog`, `voices`) — по английскому тексту фразы, не по ключу: если авторы перепишут фразу, она останется английской, а не получит чужой перевод; плейсхолдеры `{…}` сверяются, фраза с несовпадающими не подменяется. Переведено 581 уникальная фраза (588 вхождений) — сам агент, без API: разговорный игровой русский, без рода у говорящего (боты бывают и девушками, а каталог не знает, кто говорит);
2. строки вне каталога — в пакете чата `Network/Response/Speak.js`, регуляркой по всему тексту (94 правила): ответы напарников на приказы, отказы пати с причинами, торг с лавками ботов, бафы за адену, тревоги о ПК, Newbie Guide, арена, торговцы, клан. Команды игрока в подсказках остаются английскими (`sell Item Name x1 for 500 Adena`, `accept`, `.buff`) — их разбирает код L2Solo;
3. запросы к LLM (`global.fetch`, их шлюз берёт его при каждом запросе) — четыре замены «English → Russian» в промптах торговца, клана и стиля диалога и указание языка в системном сообщении: чат — по-русски кириллицей, транслит игрока понимать как русский, имена, предметы, команды и всё, что не чат (титулы, кланы, лавки), — латиницей.

Перевод — `launcher/l2hub/l2solo_ru.json` (`speech`, `say`, `fragments`, `llm`). Покрытие — строками `L2Hub RU ::` в логе сервера, их читает «Проверить всё» → «Язык ботов»: «фраз по-русски N из M», «LLM по-русски»; меньше M — значит, авторы добавили фразы, пора допереводить. Ошибка оверлея — строка в лог, сервер работает дальше по-английски. Ник и чат игрока не трогаются.

Проверено 2026-10-21: на их модулях без сервера — фразы, голоса, пакет чата («Holding this position.» → «Стою на месте.», «I can't join right now: level gap too large.» → «Сейчас не могу присоединиться: слишком большая разница в уровнях.»), без оверлея — оригинал; запрос LLM их шлюзом с оверлеем — «Ага, тут я. Чё надо?» вместо «Yes, I'm here. What do you need?»; живой сервер с оверлеем — «Язык ботов: фраз по-русски 588 из 588», штатная остановка.

**Автору проверить в игре** (включив русский в пульте C4 и перезапустив сервер):

1. Реплики ботов в чате по-русски и читаются.
2. Ввод: переключить раскладку, набрать в чате «привет» и отправить. В логе сервера появится строка `L2Hub RU :: кириллица от игрока дошла до сервера` (или «латиницей с диакритикой» — тогда клиент шлёт cp1251 как Latin-1, это лечится на сервере). Если строки нет — клиент кириллицу не отправляет; тогда писать транслитом: модели велено понимать его как русский, отвечают боты всё равно по-русски.

Другие пути, если оверлей не устроит: PR авторам L2Solo (словарь фраз в данные и настройка языка LLM) или C4 на Mobius с нашими фантомами (`L2J_Mobius_C4_ScionsOfDestiny`, порт врезок как у Interlude, десятки фантомов вместо 1700 ботов).

## Одиночка на C4: что ещё можно без правки их кода (разведка 2026-10-21)

Задача оркестратора: что ещё сделать для одиночной игры на L2Solo через слой настроек (`profiles/c4.json`, раздел `config`; пульт C4), не трогая их код. Исходники — `servers/c4/config/default.ini`, `src/GameServer/ProgressionRates.js`, README L2Solo (клон `d132ed63`). Пункты 1, 2, 4 и 5 и квесты из пункта 3 сделаны в пульте C4 (0.4.110, раздел «Пульт L2Solo в L2Hub»); остальное — предложения.

L2Solo и так собран под одиночку: боты сами качаются, торгуют, кланятся, ходят на РБ, берут игрока в пати и ходят к нему. Главное — чтобы автор знал, как этим пользоваться, и мог подкрутить мир под себя.

1. **Шпаргалка команд в пульте C4** (окно — оркестратор; сейчас нигде у нас не описаны). Команды в чате:
   - пати с ботами: `/invite` на боте — взять в спутники; `.botparty` / `.bp` — найти ботов и позвать в пати (дальние догонят); `.joinparty [имя]` — возглавить пати ботов поблизости; `.botfriends` / `.bf` — друзья и постоянная пати; `.leave`, `.kick <имя>` — отпустить;
   - спутникам словами в обычном чате: `follow`, `wait`, `hunt`, `heal`, `buff`; `.bot` / `.b` — пульт спутников, `.botstatus` / `.bs [имя]` — состояние;
   - сервис: `.buff` на боте — платный баф; `.sell` — продать всё неэкипированное за 50 %; `.afksell` / `.afkbuy` / `.afkstop` — AFK-лавка; `.trade` — обмен с ботом; `.go` — PvP на арене; `.admin` — меню GM.
   - Репутация: с ботами, которых обижаешь, пати не соберётся; с друзьями — постоянная пати.
2. **Агрессия мира — `BotPopulation.pvpAggression`** (0..1, по умолчанию 0.5, перезапуск): 0 — боты не нападают первыми (самооборона остаётся), спокойная одиночная игра; 1 — злой PvP-мир. Хороший кандидат в пульт ползунком или тремя кнопками («мирный / как у L2Solo / злой»).
3. **Скрытые рейты поверх пресета x1/x10/x50** — код читает, в `default.ini` их нет, задаются в `config.General` профиля: `spRate` (по умолчанию = `expRate`), `spoilRate` (= `dropChanceRate`), `questRewardRate` и отдельно `questAdenaRate`, `questExpRate`, `questSpRate`. Например, «квесты x3» для одиночки без ускорения кача с мобов. Итог множится на пресет: `x10` + `questRewardRate = 3` — квесты x30.
4. **Заточка — раздел `[Enchant]`**: шансы обычных, благословлённых и кристальных свитков (68/52/54 %), безопасная заточка `safeMax = 3` / `safeMaxFull = 4` (полный сет), потолок `maxWeapon` / `maxArmor` / `maxAccessory` (0 — без потолка). Для «PvP-крафт»-подобного режима — безопасная +4/+6 и шансы повыше.
5. **Режимы сервера для C4** («Хардкор», «PvP-крафт», «PvP» в «Настройках сервера» сейчас только для Mobius): на C4 их можно собрать из тех же ключей — пресет (x1 / x10 / x50), `pvpAggression` (0.5 / 0.5 / 1), `[Enchant]` (как у L2Solo / безопасная повыше / ещё выше), `General.pvp` не трогать (это флаг контекста боя ботов, а не PvP-сервер).
6. **Мелочи:** `General.maxLevel` (78 — потолок C4); `General.newbieRewardPolicy` (`strict` / `grant` / `always` — заряды новичка в квестах деревень); `BotPopulation.starterBotsPerRace` (30) — живее в стартовых зонах; `maxPlayingPopulation` (1700) — меньше ботов на слабом ПК; `coldHonestTravel` — честное время в пути у ботов вдали от игрока (реализм, не для одиночки); `ClanSimulation.enabled` — кланы ботов.

Не через настройки: олимпиада, осады, войны кланов, мировые боссы и полные квесты на профессию у L2Solo в планах («Will be added» в README) — ждать обновлений (`Обновление` выше) или второго способа C4 (L2JLisvus, `docs/C4_EMULATORS.md`).

## Приёмка: пульт C4 (ночь на 2026-10-22)

Где: лаунчер → «Мой мир» → Scions of Destiny → «Пульт». Всё применяется при следующем запуске сервера; если сервер работает — в карточке «Режим сервера» появится «Перезапустить сервер». Пока ничего не выбирал — всё как было (это «Хардкор»: ровно L2Solo).

1. **Режим сервера.** «Хардкор» — x1, их заточка и боты; «PvP-крафт» — x10, безопасная заточка +4 (+6 на полный сет), шансы 75/60/62 %; «PvP» — x50, злой мир, безопасная +6 (+8), шансы 85/75/75 %. Выбери, подтверди, перезапусти. Проверка — в логе сервера («Сервис» → лог) строка `Progress :: preset x50 | exp x50 …`, в игре — заточка до безопасной не ломает вещь.
2. **Злость мира**: «мирный» — боты первыми не нападают (самооборона остаётся), «как есть», «злой» — нападают и мстят чаще.
3. **Награды квестов** x1 / x2 / x3 / x5 — множатся на пресет рейтов.
4. **Заточка** — поля шансов (обычный, благословлённый, кристальный свиток), безопасная, потолки; «Сохранить», «Как у L2Solo» — сброс. Ключ из их `config/local.ini` главнее пульта — пульт так и подписывает.
5. **Команды L2Solo** — карточка внизу пульта. В игре проверить: `.bp` — боты сами придут в пати; `/invite` на боте — взять в спутники; в чат `follow`, `heal`, `buff`; `.buff` на боте — платный баф; `.sell` — продать лишнее; `.afksell` — AFK-лавка в мирной зоне.
6. **Второй сервер C4 — L2JLisvus** (строка «Scions of Destiny · L2JLisvus»): поставлен и проверен без клиента — логин отвечает, гейм принимает протокол 656 клиента L2Solo (0.4.150, `docs/C4_EMULATORS.md`). Ждёт первого входа: кнопка «Играть», логин и пароль любые — аккаунт создастся сам (`AutoCreateAccounts=True`). Проверить: вход в мир, чат мода, что персонаж сохраняется после «Стоп». GM-прав пока ни у кого нет.

## Режим друзей (разбор 2026-10-21; автор: для C4 не нужен)

L2Solo задуман «один живой игрок и живой мир» (их README), но код с несколькими живыми игроками справляется: горячие боты считаются вокруг каждого игрока (`HotActorLodPolicy`, `PlayerActivitySignal` — списки игроков), напарники и пати — у каждого свои, аккаунты создаются сами (`autoCreate`), `maxOnline = 1000`. Их нагрузочные проверки рассчитаны на одного игрока (`MixedRuntimeSlo`: `realPlayers === 1`), так что с друзьями растёт нагрузка на CPU: горячих ботов становится больше.

**Капканы в их коде** (`src/AuthenticationServer/Network/Request/ServerList.js`, адрес гейма, который логин отдаёт клиенту):

1. Без `[GameServer] advertisedHostname` адрес угадывается по адресу клиента: `case '10', '127':` — оператор «запятая», это только `'127'`; `192.*` — первый IPv4 адаптера с именем ровно `Ethernet` (`utils.fetchIPv4Address`, на другом имени — исключение); всё остальное — «unhandled WAN Address» и `utils.infoFail`, а он зовёт `process.exit()`. Друг через Radmin VPN (26.x) или Tailscale (100.x) без `advertisedHostname` **гасит весь сервер своим входом**. В режиме друзей `advertisedHostname` = VPN-адрес хоста — обязательно.
2. Логин и гейм слушают по одному адресу (`hostname`). Для друзей — `0.0.0.0` (тогда клиент хоста ходит на логин через 127.0.0.1, а на гейм — на свой VPN-адрес, это работает) или VPN-адрес (тогда и `L2.ini` хоста — на VPN-адрес). На `0.0.0.0` брандмауэр Windows спросит про `node.exe`, а сеть Radmin обычно «общественная» — нужно правило для `node.exe` на этой сети.

**Ещё:** `.admin` открыт всем — друзья получат ту же админку (адена, уровень, бафы). Закрыть можно нашим прелоадом (как русский оверлей: пускать `.admin` только для аккаунтов хоста), их код не трогая. Мир — один SQLite у хоста, персонажи друзей живут там же и попадают в сохранения. LLM — общий бюджет L2Solo (240 запросов в минуту на всех), расход растёт с числом говорящих игроков.

**Что сделать, если понадобится** (на 2026-10-21 автор сказал: не нужен):

1. `l2solo.layer_sections` — сетевой режим из «Друзей» (как у Mobius, `Api.set_network`): `hostname`, `advertisedHostname` = адрес выбранного VPN; сейчас C4 в «Друзьях» — «не поддерживается».
2. Пакет друга (`friendpack.py`): клиент C4 + client mod + `l2.ini` с адресом хоста (у C4 `l2.ini` на ключе комьюнити — как у Interlude, наш `l2ini.py` его пишет). Клиент — 1,8 ГБ архив с Google Drive L2Solo: друг качает сам по ссылке из их README или получает пакетом.
3. Подсказка про брандмауэр (`node.exe` на сети Radmin) в «Проверить всё».
4. По желанию — прелоад «`.admin` только хосту».
5. Проверка — только с другом (второй ПК), как суббота с Gracia Final.

## Откат интеграции

- Убрать C4 из лаунчера: `profiles/c4.json` — в Корзину. Хроника станет «не установлена», в `chronicles.json` она `l2solo`.
- Сервер: `servers/c4` целиком — в архив или в Корзину. Мир и сохранения лежат там же, в `tmp/`.
- Слой настроек и выбор из пульта — `data/l2solo/` (`c4.ini`, `c4.settings.json`), журнал сохранений — `data/backups/db/c4/`.
- Клиент — `<игры>\Lineage2-C4`, архивы — `downloads/l2solo/`.
