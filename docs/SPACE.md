# Место на диске: убрать, переустановить базу, удалить хронику

Решение автора 2026-11-06 («Реально полезно»), просьба пользователя: в окне не было удаления и переустановки базы и кнопок удалить бэкапы и сейвы, а он хотел проверить установку с нуля. Код — `launcher/l2hub/space.py`, окно — вкладка «Бэкапы», карточка «Место на диске» и кнопка «В Корзину» у каждого бэкапа.

## Что показывает

| Часть | Где лежит | Кнопка |
|---|---|---|
| Сервер: исходники и сборка | `servers/<id>/` | «Удалить хронику…» |
| База мира | MariaDB, база из профиля | «Переустановить базу…» |
| Бэкапы базы | `data/backups/db/<id>/` | «Все в Корзину», у каждого бэкапа — «В Корзину» |
| Копии настроек | `data/backups/config/<id>/` | «В Корзину» |
| Старые миры после вайпов | `data/backups/wipe/<id>/` | «В Корзину» |
| Клиент для друзей | `data/friends/<id>/` | «В Корзину» |

Размер сервера считается при открытии вкладки: у High Five это 1,3 ГБ и около 140 тысяч файлов, несколько секунд. Размер базы — по `information_schema`, только при работающей MariaDB: ради цифры её не поднимаем. Ссылки и junction внутри папок не обходятся.

## Правила

- Насовсем ничего не удаляется. Файлы и папки уходят в Корзину Windows (`backups.to_recycle_bin`). Если папка в Корзину не влезает, Windows спросит, а не удалит молча. База перед сносом снимается бэкапом.
- Только наши серверы Mobius (`wipe.check`): имя базы в профиле должно совпадать с конфигом логина, иначе снос отменяется. У L2Solo и сборок-комбайнов со своей базой карточки нет.
- Только при выключенном сервере (`wipe.blocker`): не работают ни гейм, ни логин, ни мозги, порты логина и гейма свободны.
- Переустановка и удаление требуют галочки в окне подтверждения и повтора id хроники в вызове API.

## Переустановить базу

База ставится с нуля из SQL установщика сборки, как при первой установке (`builder.fill_database`, её же зовёт `server_setup`). С нуля начинают и учётки. Порядок: бэкап «перед переустановкой базы», файлы мира вне базы (`wipe.world_files`: память мозгов, общество, журналы модов) — в Корзину, `DROP DATABASE`, новая база. Умолчания нового мира под машину (`machine.fresh_default`) ставятся так же, как при установке. Откат — «Откатить» к бэкапу «перед переустановкой базы». Чтобы сохранить учётки, есть вайп мира (`docs/WIPE.md`).

## Удалить хронику

Сервер `servers/<id>/` и профиль `profiles/<id>.json` уходят в Корзину. Хроника пропадает из списка установленных, и её можно поставить заново кнопкой «Установить»: исходники скачаются с GitLab и соберутся снова, папку клиента нужно указать заново. По галочкам:

- «И базу мира» — бэкап «перед удалением хроники», файлы мира в Корзину, `DROP DATABASE`.
- «И бэкапы базы» — все бэкапы этой базы в Корзину, вместе с только что снятым.

Без галочки «И базу» мир остаётся в MariaDB. Новая установка его подхватит: `server_setup` не трогает базу, которая уже есть. Копии настроек, старые миры и клиент для друзей при удалении не трогаются, их убирают отдельными кнопками.

У автора папка данных — корень репозитория, и `profiles/<id>.json` там в git: удаление хроники из окна покажет удалённый профиль в `git status`.

- Сервер c1 посчитан, база посчитана при работающей MariaDB.
