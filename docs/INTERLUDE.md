# Interlude в L2Hub

Создан 2026-10-20. Профиль `interlude` (`profiles/interlude.json`), сборка `L2J_Mobius_CT_0_Interlude` из свежего `master` Mobius. Хроника из списка 1.0, пока без наших модов.

## Что скачано

- Исходники Mobius: GitLab `MobiusDevelopment/L2J_Mobius`, ветка `master`, архив папки `L2J_Mobius_CT_0_Interlude` (`-/archive/master/L2J_Mobius-master.zip?path=L2J_Mobius_CT_0_Interlude`), 24,4 МБ → `downloads/L2J_Mobius_CT_0_Interlude_2026-10-20.zip`, распакованы в `servers/interlude/L2J_Mobius_CT_0_Interlude`.
- Геодата: GitHub [ChaosPaladin/l2j-geodata-project](https://github.com/ChaosPaladin/l2j-geodata-project/tree/Interlude), ветка `Interlude`, коммит `fcd5c637` от 2012-04-08 «Add geodata files for version Interlude» (экспорт проекта L2J Geodata с Google Code). Взята только папка `geodata` (sparse-clone): 166 файлов `.l2j`, 547 МБ → `downloads/l2j_geodata_interlude/` (вместе с `.git` — около 700 МБ), копия — `servers/interlude/server/game/data/geodata/`.
  - Почему не геодата H5: формат и имена файлов те же (`%d_%d.l2j`), и тайлы Interlude (X 16–26, Y 10–25) входят в тайлы H5 (X 11–26, Y 10–26), но все 166 файлов отличаются от H5 байтами — после Interlude мир менялся (крепости и прочие постройки).
  - У проекта L2J Geodata на Bitbucket (`l2jgeo/l2j_geodata`, откуда геодата H5) ветки только `master` (H5) и `C4`.

## Сервер

- Сборка — `scripts/server_build.ps1 -Id interlude`: JDK 27, как у H5 (`build.xml` требует Java 27), 1 мин 52 с, без предупреждений. Итог — `servers/interlude/build/L2J_Mobius_CT_0_Interlude.zip` (20,2 МБ), распакован в `servers/interlude/server`.
- База — `scripts/server_setup.ps1 -Id interlude`: `l2jmobiusinterlude` в общей MariaDB, 101 SQL-файл. Логин и гейм — на `127.0.0.1`, `ipconfig.xml` только с `127.0.0.1`, без GUI. Аккаунт создаётся при первом входе (`AutoCreateAccounts = True`).
- Сервер принимает протокол `746` (`AllowedProtocolRevisions` в `game/config/Server.ini`). Память — `-Xmx4g -Xms2g` (`game/java.cfg`), как у H5.
- Скрипты фазы 1 параметризованы по `Id` — правок для второй хроники Mobius не понадобилось. Капкан: `server_build.ps1` берёт первую папку с `build.xml` в `servers/<id>/`, поэтому временных копий исходников рядом не держать.

Пробный старт 2026-10-20 без клиента (`l2hub.cli start interlude --no-client`): мир за 21 с, `GeoEngine: Loaded 158 regions` (8 файлов из 166 — за краем карты Interlude), регистрация на логине как сервер 2 «Sieghardt», `error0.log` пустой, все 11 проверок «Проверить всё» зелёные, штатная остановка за 5 с. Предупреждение `Directory not found: data\buylists\custom` — у Mobius такой папки нет, это норма.

### Патчи (`patches/interlude/`)

- `0001-gameserver-bind-hostname.patch` — тот же, что у H5: у Interlude Mobius та же дыра — `GameserverHostname` читается, но гейм открывает порт на всех интерфейсах (`new InetSocketAddress(ServerConfig.PORT_GAME)`). Замечено 2026-10-20 после первого входа автора: 7777 слушал на `::`, а у `java.exe` с фазы 1 есть разрешающие правила брандмауэра для Private и Public. Патч ложится как есть; после пересборки 7777 слушает `127.0.0.1` (проверено по сокетам, `Get-NetTCPConnection`).
- Проверка «Сеть» в «Проверить всё» берёт адреса из конфигов, а не из открытых сокетов, поэтому дыру не показала. Перевести её на реальные сокеты (psutil) — после того как сессия L2Solo закончит правки `health.py`.

Хронико-независимо: патч для любой хроники собирает `python -X utf8 tools/l2hub_pvp_events.py <id> [--write]` (эталон скрипта и ключей — `tools/l2hub_pvp_events/`; если прежний 0019 уже наложен, генератор снимает его с копии дерева и собирает патч заново), для H5 и Epilogue проверено наложением (5 файлов, у Deathmatch там порог 85).

- Скрипт `custom/L2HubPvpEvents`: TvT, Deathmatch и CtF по крону из `game/config/Custom/L2HubEvents.ini`; старт — `eventStart(null)`, как у расписания Mobius. Пока идёт любой из трёх — в мире стоит менеджер (70010–70012) или кто-то записан либо на арене, — следующий не стартует: у Deathmatch на арене менеджера нет, а `eventStart` Mobius отказывает только своему же ивенту.
- Перед ареной скрипты выкидывают «оффлайн»-участников по `isOnlineInt() != 1` — а это и фантомы (у них нет клиента): все охотники вылетали, ивент отменялся «мало участников», флаг записи у них оставался до перезапуска. С 0.4.77 проверка — через `L2HubPvpEvents.offline` (не в игре или офлайн-торговец), фантомы остаются.
- Ключи (дописаны в конец `L2HubEvents.ini`): `PvpEvents = False` (по умолчанию выключено), `PvpOnlyWithPlayers = True` (старт только при живом игроке с клиентом), `PvpMinLevel = 1` (с 0.4.77; было 20 — на свежем мире охотники долго ниже 20-го, и порог не пускал ни одного; порог вместо 76 — константа `MINIMUM_PARTICIPANT_LEVEL` в трёх скриптах теперь берёт его через `L2HubPvpEvents.minLevel(76)`; при `PvpEvents = False` порог прежний), `TvT = 0 */3 * * *`, `Deathmatch = 0 1-23/3 * * *`, `CtF = 0 2-23/3 * * *`.

### Суперчемпион (`0020-super-champion`, 0.4.103)

Идея автора 2026-10-21 (`docs/PLAN.md`, «Моды мира»): третий уровень чемпионов над красными и синими — мини-РБ. Задачу поставил оркестратор, Interlude — первым.

- **Что в игре.** При каждом появлении моба (уровни, пассивность и прочее — общие с чемпионами `ChampionMinLevel`–`ChampionMaxLevel`, только при `ChampionEnable = True`) сначала бросается шанс суперчемпиона `SuperChampionFrequency` (0,1 %), затем красного, затем синего. Суперчемпион: титул «Legendary Champion», красный круг, над моделью эффекты `SuperChampionEffects` (`BIG_BODY` — моб крупнее, как квестовый босс; `ULTIMATE_DEFENCE` — свечение скилла Ultimate Defense, у NPC — скилл 5044), HP x20, регенерация x2, P./M. Atk x3, скорость атаки и каста x1.5, опыт и SP x20, шанс дропа x10 и количество x2, адена x10, предметы-награды `6393,10` (шанс — общие `ChampionRewardLowerLvlItemChance`/`HigherLvl`). Атака не x10: так моб с пары ударов убивает игрока своего уровня, x3 — как удар РБ того же уровня (предложение агента, правится ключом).
- **Объявление.** `SuperChampionAnnounce = Region` — игрокам в том же регионе карты (`MapRegionData.getMapRegionLocId`), в чат-объявление и на экран; `World` — всем, `Off` — нет. Текст — `SuperChampionAnnounceText` (`%name%`, `%level%`, `%town%` — ближайший город региона из `mapregion`). Шрифты чата и экрана у клиента Interlude русские (раздел «Клиент»). В лог сервера — строка «SuperChampion: имя (уровень) at x, y, z — текст».
- **«Золото».** В пакете NPC Interlude шлёт только обычную маску эффектов: особые (`INVINCIBILITY` — золотая сфера Celestial Shield и др.) клиент не увидит. Кандидаты взяты по скиллам датапака Interlude (значит, клиент их рисует): `ULTIMATE_DEFENCE` (скиллы 110, 5044), `BIG_BODY` (4692 Quest BOSS Big Body, 4318 Ultimate Buff). Как именно выглядит — проверить в клиенте: GM-командой `//ave_abnormal <ЭФФЕКТ>` на цели, затем вписать выбранное в `SuperChampionEffects`.
- **Ключи** — блок в конце `game/config/Custom/ChampionMonsters.ini`: `SuperChampionEnable` (имя для выключателя в «Моды и ивенты», по умолчанию `True`), `SuperChampionFrequency`, `SuperChampionTitle`, множители `SuperChampionHp`, `…HpRegen`, `…RewardsExpSp`, `…RewardsChance`, `…RewardsAmount`, `…AdenasRewardsChance`, `…AdenasRewardsAmount`, `…Atk`, `…SpdAtk`, `SuperChampionRewardItems`, `SuperChampionEffects`, `SuperChampionAnnounce`, `SuperChampionAnnounceText`. Новое значение — со следующего запуска сервера.
- **Проверка 2026-10-21** (ключи по умолчанию): на старте 34 суперчемпиона на 34 158 спавнов, уровни 20–80, кириллица текста из ini прочиталась (кодировка конфигов у Mobius — по умолчанию JDK, у JDK 27 это UTF-8), `error0.log` пустой. Эффекты и статы глазами не проверены: нужен клиент — первый же суперчемпион у автора. В развёрнутый `ChampionMonsters.ini` блок дописан целиком (копия прежнего — `data/backups/config/interlude/2026-10-21_23-24-36_superchampion/`).

- **Охотники собираются на суперчемпиона** (ядро фантомов epilogue-h5, 0.4.111, `HunterSuperChampions` в `PhantomHunters.ini`): раз в 2 минуты, пока нет рейда, `PhantomRaid` ведёт пати охотников на живого суперчемпиона (`SuperChampion.alive()`), лидер — на 4–8 уровней выше цели, сбор 2 минуты. Interlude пересобран 2026-10-22 01:48, ключ дописан в развёрнутый конфиг (бэкап — `data/backups/config/interlude/2026-10-22_01-50-22/`). Прогон с временными `ChampionMinLevel = 1` и `SuperChampionFrequency = 5` (охотники Interlude — 7–12-го уровня, а чемпионы с `ChampionMinLevel` 20, лидеру нужно на 4 больше): в 01:56 «LunaTik (12) leads a raid on super champion Gray Wolf (4)», пятеро; в 02:00:54 «raid killed Gray Wolf in 269 s», `error0.log` пустой. **Перенос на другие хроники** (High Five, Gracia Epilogue — epilogue-h5; Classic, Essence — classic-essence). Логика — в общем классе `java/org/l2jmobius/gameserver/entity/actor/SuperChampion.java` (эталон — `tools/l2hub_super_champion/SuperChampion.java`): эффекты над моделью (`onChampion`), объявление (`announce`), живые суперчемпионы для охотников (`alive()`, `isSuper`). В файлах Mobius — только врезки поверх патча чемпионов `0002` (record `ChampionMonstersConfig.Tier`):

1. `ChampionMonstersConfig`: `CHAMPION_SUPER = loadTier(config, "SuperChampion", Team.RED, …)`, `SUPER_CHAMPION_ENABLE`, `SUPER_CHAMPION_EFFECTS` (разбор имён `AbnormalVisualEffect`), `SUPER_CHAMPION_ANNOUNCE`, `SUPER_CHAMPION_ANNOUNCE_TEXT`;
2. `Attackable.setChampion`: после `_champion = champion;` — `SuperChampion.onChampion(this, champion);`;
3. место броска шанса чемпиона (у Interlude, H5 и Epilogue — `Spawn`): сначала `SuperChampion` при `SUPER_CHAMPION_ENABLE`, затем красный и синий со сдвигом на шанс суперчемпиона; суперчемпиону — `SuperChampion.announce(npc)`;

Для Interlude, H5 и Epilogue всё делает `python -X utf8 tools/l2hub_super_champion.py <id> [--write]` (патч `patches/<id>/0020-super-champion.patch`, проверка наложением байт в байт; холостой прогон на H5 и Epilogue — байт в байт). У Classic и Essence шанс чемпиона бросается не в `Spawn` (`_champion = ChampionMonstersConfig.CHAMPION_…` в `Attackable`): генератор называет якоря, которые не легли, — пункты 2 и 3 там руками в своём месте броска. Имена пакетов (`MapRegionData`, `ChatType`, `CreatureSay`, `ExShowScreenMessage`) в `SuperChampion.java` сверить с хроникой. Эффекты подобрать по своему клиенту: у H5 особые эффекты в пакете есть.

### Семь печатей малого мира (`0026-sevensigns-small-world`, 2026-10-22)

Разведка по коду Mobius Interlude (`mechanics/sevensigns/SevenSigns.java`, `DungeonGatekeeper`, `SignsPriest`, обработчик `Festival`): что мешает одному игроку.

- **Цикл — две недели, жёстко в коде:** соревнование неделю (вступление у жрецов — только в эту неделю и заново каждый цикл, сдача печатей, Фестиваль тьмы), итоги 15 минут, неделя проверки печатей. Смена — понедельник 18:00 (`PERIOD_START_*`). Настройкой не меняется.

- **Печать** достаётся победителю, если за неё голосовало от 35 % его стороны (удержать прежнюю — от 10 %). Каждый голосует за одну печать, поэтому одиночка за цикл получает одну печать из трёх.
- **Катакомбы и некрополи** (`DungeonGatekeeper`). В неделю соревнования туда пускают только вступивших (любая сторона). В неделю проверки — только победителей и только при печати у победителя: катакомбы — при Гнозисе, некрополи — при Алчности; при ничьей — любого вступившего. Одиночке половину времени закрыта половина подземелий, а если не вступил в этом цикле — все.
- **Маммон.** Купец (магазин древних адена) приходит только в неделю проверки и только при Алчности у победителя, кузнец (особые свойства оружия) — только при Гнозисе. - **Фестиваль тьмы** — пати от `AltFestivalMinPlayer` (5), записывает лидер, без пати не пускают вовсе.
- **Взнос Рассвета** (50 000 адены или свидетельство лорда, после второй профессии) одиночке не мешает — не трогаем.
- Мир автора 2026-10-22: цикл 1, неделя соревнования, к сторонам никто не примкнул, печатей ни у кого.

### Язык наших текстов (`0029-l2hub-language`, 2026-10-22)

Окно лаунчера двуязычное с 0.4.155, а в игре наши моды писали только по-русски. Ключ — `L2HubLanguage = ru|en` в `game/config/Custom/L2HubWorld.ini` (общий ini модуля фантомов, есть у всех хроник Mobius; лаунчер пишет его по языку своего окна, применяется после перезапуска сервера; нет ключа — ru).

Генератор `tools/l2hub_lang.py <id> [--todo F] [--write]` вставляет язык одинаково в любой вариант файлов хроники:
- каждый русский строковый литерал в коде (кроме комментариев и строк лога `LOGGER`) оборачивается в `tr("…")`;
- в начало класса — `L2HUB_ENGLISH` (читает ключ), таблица `L2HUB_EN` «русская строка → английская» только из строк этого файла и `tr()`: при en — английская, чего в таблице нет — остаётся по-русски, как у переводчика окна лаунчера;
- общая таблица — `tools/l2hub_lang/en.json` (156 строк на пять хроник), `--todo` выгружает строки без перевода;
- суперчемпион: текст объявления — из `SuperChampionAnnounceText` (у нас русский), при en и русском тексте — английский текст Mobius по умолчанию.

Что переведено: окно `.world` («Мир сейчас»), записи «Летописи» (`L2HubChronicle.json`), объявления эльпи и суперчемпиона, самопроверка модов (`L2HubSelfTest.json`, видна в «Проверить всё»). Олимпиада, Семь печатей и эпики малого мира текстов в игре не добавляют — только комментарии ini, их переводит окно лаунчера. Не переведено: строки лога сервера (не для игрока); объявления самих PvP-ивентов TvT, CtF, Deathmatch — английские у Mobius; окна-html (доска Alt+B, окно моба по Shift+клику из 0014, диалоги событий из 0016) — для них у Mobius свои языковые папки (`MultilingualSupport.ini`, `data/lang/<язык>/html`): наши русские html туда, английские оригиналы — на место, язык по умолчанию — от `L2HubLanguage`. Это следующий шаг; доска, `.buddy`, `.hunters` — ядро, стык у epilogue-h5.

Interlude: патч записан (5 файлов, 154 строки), сервер собран целиком, ключ — в развёрнутом `L2HubWorld.ini` (копия прежнего — `data/backups/config/interlude/2026-10-22_21-06-35/`), javac всех скриптов — без ошибок.
