# «Мой мир» (World Control v1) — аудит и предложение

Создан 2026-10-18 по ТЗ «L2Hub — World Control v1» (этап A: аудит и макет). Рабочий интерфейс не менялся.

Макет — `docs/design/world/mockup.html`, один файл без сборки: данные внутри, шрифты — Google Fonts, как у лаунчера. Его можно открыть в браузере двойным щелчком или в панели предпросмотра (`world-mockup` в `.claude/launch.json`, порт 8790).

## 1. Что проверено

- **UI:** `launcher/l2hub/ui/index.html`, `app.js`, `styles.css`. Главный экран хроники, «Настройки» (полноэкранный вид `.view`), выдвижные «Друзья» и «Сервис». В «Сервисе» сейчас живут охотники, мозги-стратег и мозги фейков.
- **Опрос:** `state()` раз в секунду. `hunters()` — раз в 10 секунд, только пока открыт «Сервис».
- **API** (`l2hub/api.py`): сигнатуры и ответы сняты с работающего High Five 2026-10-18 22:08–22:17 теми же методами, что вызывает окно:
  - `state`, `hunters`, `brain_settings`, `settings_schema`;
  - `brain_settings` отдаёт только «ключ есть/нет», сам ключ не читался.
- **Gracia Final:**
  - `hunters()` → `{ok: false, error: "В этой сборке нет охотников-фантомов."}`;
  - `brain_settings()` → `{ok: false, error: "У этой хроники нет мозгов фейков."}`.

## 2. Какие данные есть для каждого экрана

| Экран | Что показать | Откуда |
|---|---|---|
| Обзор | хроника, состояние сервера, аптайм, онлайн | `catalog()`, `state().components.game` |
| | режим охотников, сколько в мире, живых игроков | `hunters().mode`, `items[].phase`, `players` |
| | напарники (сколько) | **нет метода** — см. 3.1 |
| | разум: модель, на связи или нет, последний ответ, сбои модели, неудачные ответы, решений с запуска | `state().components.brain` (`state`, `key`, `llmOk`, `lastReplyAt`, `errors`, `lastError` — сбои самой модели; `bad`, `lastBad` — ответы не в дело; `limited` — свой лимит в минуту; `decisions`), стратег — `hunters().strategy.when` |
| | чем занят мир, экономика, уровни, последние решения | `hunters().items` (`phase`, `adena`, `earnedPerHour`, `quest`, `professionDue`, `store`, `level`, `strategy`) |
| Население | имя, уровень, профессия | `items[].name`, `level`, `cls` (из базы, `classList.xml`) |
| | где, чем занят | `spot`, `town`, `party`, `phase` (HUNT, TOWN, STORE, RECRUIT, PARTY, DEAD) |
| | адена, доход в час | `adena`, `earnedPerHour` |
| | стратег: решение, мысль, когда, следующее | `strategy.{at, decision, thought}`, `nextThink` |
| | квест, долг за профу, лавка с товаром и ценами | `quest.{level, until, ready}`, `professionDue`, `store.{title, until, items[]}` |
| | сброс одного и всех | `reset_hunters(id, names)` — сам снимает бэкап `before-reset` |
| Напарники | имя, роль, уровень, класс, путь класса, прозвища, характер | **нет метода**: `L2HubPhantoms.xml` (элементы без `kind="hunter"`), `L2HubPhantomPersonas.json`, база — см. 3.1 |
| Разум | модель: режим, адрес, модель, ключ есть/нет, длина ответа, тариф | `brain_settings()`, `save_brain_settings()`, `brain_models()`, `brain_test()` |
| | стратегия: когда, решений в час, запросов в минуту, шанс сказать вслух, потолок стратега | `hunters().strategy`, `set_hunter_strategy()` |
| | расходы: сегодня, неделя, всё время, токены на запрос, ответы и ошибки с запуска | `brain_settings().usage`, `hunters().strategy.tokensIn/Out`, `state().components.brain` |
| | лента решений стратега с итогами, выводы и опыт охотников, разговоры фантомов, «забыть» (`docs/MIND.md`, шаг 5) | `mind_view()`, `mind_forget()` |
| Создатель | ключи мира с текущими значениями и комментариями из ini | `settings_schema()` → `save_settings()` (бэкап конфигов сам) |

## 3. Несовместимости и недостающие данные

1. **Напарники — нет API.** Данные есть, но только на диске и в базе. Предлагаю один метод только на чтение, `companions(id)`: имя, роль, прозвища, путь класса, характер, уровень, класс, «в мире». Управлять напарниками из лаунчера нечем (они живут рядом с игроком), в UI это так и написано.
2. **Свежесть данных охотников не видна.**
   - `hunters()` молча возвращает `live: false`, если `L2HubHunters.json` старше минуты.
   - Чтобы честно писать «обновлено N с назад» и «устарели», нужен `liveAt` — поле `time` из того же файла. Это добавка в ответ, сигнатура не меняется.
3. **«Ждёт перезапуска» не определяется.**
   - На ходу сервер перечитывает только `PhantomHunters.ini` (раз в 10 с).
   - `PhantomParty.ini`, `Phantoms.ini`, `FakePlayers.ini`, `Rates.ini` читаются только при старте (`ConfigLoader`), `data/brain/settings.json` — со следующей реплики.
   - В лаунчере уже есть сравнение «конфиг новее процесса гейма» (`network_state().restartNeeded`). Предлагаю обобщить его в `restart_needed(id)` со списком файлов.
4. **У ключей нет диапазонов и умолчаний.**
   - В ini строк `Default:` почти нет, у части ключей пустое описание (общий комментарий на группу: `HunterQuestLevels`, `HunterStoreMinMinutes` и др.).
   - Подписи, пояснения, группы, диапазоны и «на ходу или после перезапуска» для «Создателя» — таблица метаданных в UI (в макете — `META`, 42 ключа).
   - Диапазоны указаны только там, где они достоверны: пределы стратега из `api.py`, проценты 0–100.
   - Показываются только ключи, которые есть в схеме выбранной сборки.
5. **Карточка охотника — только то, что сервер пишет.** Опыта в %, HP, смертей, обид и шмота в `L2HubHunters.json` нет: стратег их знает, но наружу не пишет. Без правки патчей их не показать; в v1 и не показываем, в карточке так и сказано.
6. **«LLM подключена» без платного запроса.** Состояние берётся из `state().components.brain`: сервис мозгов поднят, ключ есть, `llmOk` не `false`, есть `lastReplyAt`. `llmOk` — удался ли последний запрос к модели: `false` только при сбое самого запроса (нет ключа, сеть, HTTP, таймаут, мусор вместо ответа API), до следующего удачного. Кривой ответ стратега (нет тега из вариантов, пустая строка) — не отвал: это `bad`, за охотника решают правила. Сервис мозгов до 0.4.265 `llmOk` не отдаёт — тогда по `lastError`, как раньше. Сам `brain_test()` — только по кнопке, это платный запрос.
7. **Лимитов в деньгах нет.** Есть потолки запросов (40 в минуту на всё, стратегу — до 20) и тариф для оценки. Экран «Разум» так и пишет.
8. **`confirm()` в старом коде:** сброс охотников и откат бэкапа. Новые сценарии — через стилизованный `.modal`; откат бэкапа в «Сервисе» можно перевести тем же компонентом отдельно.
9. **Ловушка, найденная в макете:** класс кнопки `.world` совпал с классом вида и спрятал кнопку. В рабочем коде — свой префикс классов (`w-…`).

## 4. Структура интерфейса

- **Вход:** кнопка «Мой мир» в ряду действий главного экрана между «Друзья» и «Сервис». Открывает полноэкранный вид поверх тела окна, как «Настройки»; закрытие — крестик или Esc.
  С 2026-10-20 (оболочка v3, 0.2.29) «Мой мир» — раздел L2Hub в полоске слева, а не вид хроники: открывается мир запущенной хроники, иначе выбранной; карточка «Живой мир» на «Обзоре» хроники ведёт туда же.
  С 0.2.30 сверху навигации — выбор мира: хроники, у которых есть `phantoms/<id>` (выбор помнится, иначе — запущенная хроника с модулем); внизу «Для всех миров» → «Модуль фантомов»: где модуль стоит, свежий ли он в сборке сервера (хэши `phantoms/` против `servers/<id>/.module_manifest.json`, `Api.phantoms_status`) и «Пересобрать» — тот же `scripts/server_build.ps1` фоновой задачей (`Api.rebuild_module`, только у выключенного сервера).
  С 2026-10-20 (по просьбе автора «карту сделать для всех хроник») у каждого мира — экран «Карта»: подложка — тайлы `npetrovski/l2-world-map` в `ui/maps` (только локально, `tools/world_map_tiles.py`), точки — `Api.world_map`: охотники, лавки (охотник в фазе STORE), напарники и живые игроки. Пока сервер не пишет координаты в `L2HubHunters.json`, места — из базы (на последнем сохранении персонажа), «и не в игре» — где персонаж вышел. Хроника без фантомов и без своего интерфейса (Gracia Final, Essence) — мир «только карта». На главной хроники — «Пульт и карта»: у C4 — карта и пульт L2Solo (и «Настройки сервера» C4 ведут в его пульт), у остальных — «Карта» их мира.
- **Шапка вида:**
  - «Мой мир · <хроника>»;
  - плашка сервера (работает · аптайм · живых, запускается, выключен — «мир стоит»);
  - плашка свежести (живые · N с назад, устарели, нет ответа от API).
- **Слева разделы:** Обзор, Население (число охотников), Напарники (число), Разум (точка состояния), Создатель (точка «не сохранено»). Внизу строка «Позже: Общество и Летопись — в docs, без заглушек».
- **Обзор:**
  - четыре плитки: охотники с переключателем режима, напарники, разум, игроки;
  - «Чем занят мир» — полоса по фазам, клик ведёт в «Население» с фильтром;
  - экономика: адена у всех, медиана дохода, квесты, копят на профу, лавки;
  - гистограмма уровней, последние 5 решений стратега с мыслями.
- **Население:**
  - поиск, фильтр-чипы по занятиям, сортировка (уровень, имя, доход, адена);
  - таблица: имя, ур., профессия, «где и чем занят» (цвет фазы и место), адена, доход в час, решение стратега;
  - справа карточка выбранного;
  - «Сбросить прогресс» и «Сбросить всех» — через диалог с предупреждением и строкой про бэкап `before-reset`.
- **Напарники:** две карточки (Vesna, Mityai) и «Как с ними играть»: `.buddy` и Alt+B, приказы словами в пати, шёпотом и в белый чат. Только справка.
- **Разум:**
  - строка состояния — одно из: на связи, мир без LLM (нет ключа), LLM недоступна, стратег выключен; мозги спят вместе с сервером;
  - вкладки «Мысли», «Выводы», «Память» (`docs/MIND.md`, «Шаг 5 — как сделано») и «Модель и стратег» — три колонки: Модель, Стратегия, Расходы;
  - выключенная LLM не выглядит как остановка мира.
- **Создатель:**
  - слева шесть групп из ТЗ;
  - справа параметры: название, пояснение, ключ и файл, допустимые значения, «на ходу, за ~10 с» или «после перезапуска гейм-сервера»;
  - внизу «не сохранено: N, из них после перезапуска: M»;
  - после сохранения — баннер «ждёт перезапуска» с кнопкой `restart_game()`;
  - правки живут в памяти вида и не теряются при переходе между разделами;
  - стратег — в «Разуме», служебные ключи — в «Настройки» → «Все настройки».
- **Опрос:**
  - `state()` — как сейчас;
  - `hunters()` — раз в 10 с, только пока открыт «Мой мир» на «Обзоре» или «Населении»;
  - один запрос в полёте, при закрытии таймер снимается;
  - `brain_settings()` — при входе в «Разум», `settings_schema()` — при входе в «Создатель»;
  - `mind_view()` — при входе в «Разум» и раз в 10 с, пока открыты «Мысли», «Выводы» или «Память».
- **«Сервис» после внедрения:** живой лог, папки, персонажи и права GM, бэкапы. Блоки охотников и мозгов переезжают в «Мой мир», на их месте — строка-ссылка «Охотники, мозги и правила мира — в «Мой мир»». Функции не теряются.

## 6. Будущие направления — не в v1

Без экранов и заглушек:
- массовое население: сотни и тысячи персонажей;
- активные, фоновые и офлайн-персонажи; регулирование целевого онлайна и автоматический подбор числа активных;
- фоновая экономическая симуляция;
- отношения между ботами, их социальная сеть и визуализация — «Общество»;
- кланы, войны, осады, олимпиады;
- история событий мира — «Летопись».

## 8. Внедрено (2026-10-18, этапы B–D)

Автор согласовал макет, «Мой мир» встроен в лаунчер по разделам 4–5.

**Что сделано:**
- **API** (`l2hub/api.py`), только добавки:

  - `restart_needed(id)` — конфиги гейма, сохранённые после старта гейм-сервера; `PhantomHunters.ini` не в счёт.

  - кнопка «Мой мир» на главном экране и вид `#viewWorld` в `index.html`;
