# Обычная сборка Epilogue

Игровые функции локального модуля перенесены в редактируемые Java-исходники и обычные патчи Epilogue. `GameServer.jar` собирается штатным Ant; внешний Java-agent и отдельный стартовый BAT ему не нужны.

Исходники функций находятся в `phantoms/epilogue/java`, обработчики — в `phantoms/epilogue/dist/game/data/scripts`, врезки — в `patches/epilogue`. Патч0512 сохраняет действовавшие функции пачек, кланов, Олимпиады, экипировки, расходников и платных услуг, включая вход/воскрешение/наблюдение/сохранение выбранных уровней навыков. Локальные имена классов `local.l2` оставлены для совместимости; в этой сборке это обычные классы внутри серверного JAR, без инструментирования JVM. Ключи переменных персонажей и файлы сохранённых пачек сохраняются.

Подготовка и сборка:

```powershell
launcher\.venv\Scripts\python -m l2hub.cli fetch epilogue
launcher\.venv\Scripts\python -m l2hub.cli build epilogue
```

Для уже существующей установки `fetch` повторно не нужен. Сборка использует закреплённый Mobius commit из `mobius_pins.json`, затем core, Epilogue, отсортированные патчи и glue. Исходные правки не вносятся вручную только в каталог `servers`.

Настройки читаются из обычных INI сервера. Играющий GM, отдельное снятие штрафов эпиков и всех рейд-боссов, личная пачка, имена, расходники, платные услуги и виды свитков доступны в графических настройках L2Hub. Новые общие шаблоны используют значения Java по умолчанию: чужие рейты, цены, имена и население700 не становятся настройками для всех установок. Текущее настроенное население и фактическое число шаблонов XML показываются отдельно.

Личные данные, банк памяти мозгов, БД и пользовательские конфиги не хранятся в Git. При первом переходе нужно отдельно перенести **актуальный** `local-plugin/state/ClanRecruitment.properties` в `game/data/ClanRecruitment.properties`, сохранить текущие XML баланса и населения, личные `.properties`, персонажные переменные и эмблемы. Обычная пересборка Epilogue сохраняет изменённые файлы данных; при конфликте новая версия сборки кладётся в `.data_new`, а SHA последней известной версии — в `.data_base/index.json`. Эти каталоги не являются пользовательским прогрессом или заменой резервной копии БД.

Проверки мира выполняются существующим `tools/selftest_run.py` на копии базы. Штатные тесты могут предполагать другой состав шаблонов или трёхчасовые баффы; это нужно отличать от регрессии при сохранении локальных настроек. Сборка, файловая установка и проверка действий живым игроком отмечаются отдельно.

Этот перенос не включает незавершённую клиентскую панель соперника, изменение геодаты, расследование клиентских зависаний и отклонённую перестановку очереди Олимпиады. Публикацию и приёмку основной стороной ведёт координатор; локальная сборка не означает опубликованный общий релиз.
