# Русские диалоги: страницы сервера

Перевод страниц High Five: пробная партия, оценка, перевод всего текста в облаке и его сбор. Решение автора — `docs/PLAN.md`, «Решения», 2026-11-02 вечер. Клиент не меняется: названия предметов, журнал квестов и системные сообщения лежат в его `.dat` и остаются как есть.

## Как это работает

- Русская страница лежит рядом с английской: `dist/game/data/lang/ru/data/<тот же путь>`.
- Страницу выбирает `HtmCache.getHtm(player, path)`: при языке `ru` берёт русскую, если её нет — английскую. При `en` префикса нет, остаётся английская. Язык задают `L2HubLanguage` (новому персонажу) и команда `.lang`.
- Русская страница без английского близнеца не показывается: `Npc.getHtmlPath` проверяет путь без префикса.
- Клиент получает страницу как есть. Лимит пакета — 17 200 знаков (`AbstractHtmlPacket.setHtml`), дальше обрез; русский текст короче английского, партия в лимит не упирается.

## Инструменты

| Что | Где |
|---|---|
| Сверка русских страниц с английскими | `tools/ru_pages_check.py` |
| Выгрузка кусков, память переводов, сборка страниц, база и патч | `tools/ru_pages.py` |
| Пакет для облачных сессий, сбор ответов | `tools/ru_pages_cloud.py`, заготовки — `tools/ru_pages/cloud/` |
| Решения по терминам облачного перевода: правки памяти и строки глоссария | `tools/ru_pages_terms.py`, его зовёт `collect` |
| Память переводов: кусок английского → кусок русского | `tools/ru_pages/tm_ct26_highfive.tsv` |
| Глоссарий | `docs/RU_GLOSSARY.md` |
| Самопроверка на сервере | `patches/ct26_highfive/0221-ru-pages-selftest.patch`, `HuntersSelfTest = L2HUBRU` |

Переводится не страница, а кусок: блочные теги и переводы строк режут текст, `font`, `b`, `i`, `u` остаются внутри куска. Один английский кусок в памяти один, поэтому «разный перевод одного текста» невозможен, а страница собирается заменой кусков в английском файле: теги, `bypass`, подстановки и переводы строк совпадают сами.

## Порядок работы над партией

База и патч считаются от чистого архива с модами, а не от `servers/`: там чужие незалитые правки. `base` и `patch` запускать питоном из `launcher/.venv`, остальное — любым.

```
python -X utf8 tools/ru_pages.py base --archive downloads/L2J_Mobius_CT_2.6_HighFive_2026-10-16.zip --patches patches/ct26_highfive --before 0220 --out <база>
python -X utf8 tools/ru_pages.py dump --tree <база> --list <партия> --tm tools/ru_pages/tm_ct26_highfive.tsv --out <куски>.txt
```

`<куски>.txt` — контекст для перевода: страница, NPC и его пол, кнопка или текст, номер куска. Перевод — строки `номер перевод` в отдельном файле.

```
python -X utf8 tools/ru_pages.py merge --dump <куски>.txt.json --ids <перевод> --tm tools/ru_pages/tm_ct26_highfive.tsv
python -X utf8 tools/ru_pages.py build --tree <база> --list <партия> --tm tools/ru_pages/tm_ct26_highfive.tsv --out <страницы>
python -X utf8 tools/ru_pages_check.py --tree <база + страницы> --list <партия> --tm tools/ru_pages/tm_ct26_highfive.tsv --shared
python -X utf8 tools/ru_pages.py patch --base <база> --tree <страницы> --header <заголовок> --out patches/ct26_highfive/<номер>-ru-pages-<партия>.patch
```

Номер патча партии — выше всех, что есть; база при этом считается `--before <номер>`.

## Сверка

`tools/ru_pages_check.py` падает с кодом 1 при любом расхождении; `--selftest` прогоняет порченые страницы (28 случаев).

- Скелет: теги, порядок, атрибуты, `bypass`, `action`, ссылки на предметы, переводы строк, конец файла. Подпись кнопки сверяется отдельно.
- По каждому куску: подстановки `%…%`, сущности `&…;`, числа.
- Текст: нет английского близнеца, не UTF-8, BOM, недопустимые символы (клиентский шрифт), английский кусок без перевода, латиница вне глоссария, термин глоссария переведён не той основой.
- Между страницами: один английский кусок переведён по-разному, близнец переведённой страницы оставлен английским.
- `--tm`: страница разошлась с памятью переводов.
- `--shared` — не ошибки, а швы: куски партии на непереведённых страницах, кнопки на английские страницы, кнопки-скрипты, фразы, разрезанные между страницами.

Итог партии: 214 страниц, 546 кусков, 179 терминов, ошибок 0. Порча настоящих страниц партии (имя выпало, цвет, `bypass`, число, латиница) падает на каждом случае.

## Проверка на сервере

Проверено 2026-11-02 на копии базы (`L2HUB_HOME=<рабочая папка>\L2Hub_rttest`), порты под `data/agents/lock.py`. Страницы партии и самопроверка `0221` положены новыми файлами поверх собранного сервера: дерево делят соседние сессии, и пересборка выбросила бы их незалитые патчи. После прогона файлы убраны, конфиги возвращены байт в байт. `HuntersSelfTest = L2HUBRU`, два запуска: `HtmCache = False` и `HtmCache = True`. Оба раза 18 проверок, 0 ошибок; `DEADLOCK REPORT` нет, `error0.log` пустой.

## Швы

Что игрок увидит на границе перевода.

- **Клиент.** Предметы, журнал квестов, названия квестов, системные сообщения, имена NPC над головой — английские. В диалоге «письмо Дарина», в сумке `Darin's Letter`. Самый заметный шов партии, и в страницах он не лечится.
- **Выбор квеста.** Окно со списком квестов сервер строит в Java из строк клиента (`<fstring>`): кнопка «Квест» переведена, названия в списке английские.
- **Кнопки-скрипты.** `FirstClassTransferTalk`, `ClanMaster`, `AllianceMaster`, `CharacterBirthday`, `RaidbossInfo` отдают свои страницы из своих скриптов, сверка их не обходит: в партии они остались английскими. Список телепортов у телепортиста формируется так же, названия городов идут оттуда.
- **Общие куски.** 105 из 546 кусков партии есть и на непереведённых страницах: `Quest` (1494), `Return` (1136), `Back` (571), `Learn skills.` (228). Пока перевод не полный, игрок в другой деревне увидит английские кнопки и русские общие ответы.
- **Обучение.** Переведено только для человека, воина и мага. Остальные народы получают английские страницы `Q00255_Tutorial`, а кнопки наставников 30008, 30009, 30017, 30019 — русские.
- **Разрезанные между страницами фразы.** В партии нет. По всей игре эвристика находит одну: `html/default/30754.htm` кончается «…The Heart of Warding», `30754-1.htm` начинается с многоточия. Эвристика смотрит только страницы с одной кнопкой, поэтому ноль здесь не доказательство: такие места надо читать при переводе их партии.

## Где перевод вышел слабым

- **Один голос.** Правило «к игроку на вы» и единый словарь выравнивают голоса: стража, наставники и торговцы звучат одинаково и суховато. Шутки и просторечие оригинала пересказаны ровнее, чем написаны (`Right On!`, реплики торговцев).
- **Имена без канона.** Русской локализации High Five под рукой нет. Города и боги взяты по устоявшемуся написанию, редкие имена — транслитерацией (`Hieros`). Спорное оставлено латиницей: `Soulshot`, `Spiritshot`, `Wondrous Cubic`, `Cube Fragments`, `Giant's Codex`, `Airship Controller`. Это честно по глоссарию, но текст местами пёстрый.
- **Предметы по-русски при английском клиенте.** Квестовые предметы в репликах переведены ради связности, а на экране они английские. Игрок не найдёт в сумке то, что назвал NPC, дословно; помогает только то, что они у него одни.
- **Подпись говорящего.** `Adventure Guildsman:` стоит у NPC обоих полов, поэтому стала «Гильдия Искателей Приключений:».
- **Вольные места.** Два куска заведомо не дословны: `You look like a nice, young adventurer` стало «Вы, я вижу, ищете приключений», `What would you like to trade?` — «Что желаете купить или продать?». Других таких мест я не отмечал, вторым читателем текст не проходил, так что список неполон.
- **Ошибки оригинала.** Варианты одного имени в английском (`Cedric`/`Sedrick`, `Baulro`/`Baulo`, `Harrys`/`Harris`, `Yohanes`/`Johanes`, `Biotin`/`Viotin`, `Guard`/`Sentry Arnold`, `Trader`/`Merchant Jackson`) сведены к одному. `Grand Magister Roien` на 30008-006 — вероятно, ошибка источника, переведено дословно. Лишний `</font>` в `Q00101` 30283-04 оставлен: скелет не меняется.

## Что нельзя проверить без клиента

- Кириллицу в окнах: глифы и шрифт диалога, окна квеста (`NpcQuestHtmlMessage`) и окна обучения (`TutorialShowHtml`).
- Переносы и длину строк: русский в 0,86 раза короче английского в среднем, но отдельные подписи длиннее и могут не влезть в кнопки, у которых ширина задана (`Initial Screen`, `width=80`).
- Настоящие клики: обход кнопок идёт по файлам, настоящий клиент шлёт `bypass` сам.
- Как выглядят строки клиента рядом с русским текстом: `<fstring>`, названия предметов в ссылках.
- Смену языка на глазах: команда `.lang` перерисовывает NPC, сервер это делает, а как выглядит в клиенте, не видно.

## Перевод в облаке

Пакет для облачных сессий собирает `tools/ru_pages_cloud.py build` в `<рабочая папка>\L2Hub_cloud`, это отдельная папка со своим git. Сессия видит только его: сервера, истории проекта и личного там нет.

```
python -X utf8 tools/ru_pages_cloud.py build --base <база с модами> --archive downloads/L2J_Mobius_CT_2.6_HighFive_2026-10-16.zip --tm tools/ru_pages/tm_ct26_highfive.tsv --glossary docs/RU_GLOSSARY.md --out <папка пакета>
```

Что внутри:

- `AGENTS.md` (и `CLAUDE.md` со ссылкой на него) — задача для переводчика без контекста проекта, голос, формат ответа, стоп;
- `docs/RU_GLOSSARY.md`, `docs/SAMPLES.md` — глоссарий и 30 образцов пробной партии;
- `tm/` — память переводов; уже переведённое в части не попадает;
- `parts/<часть>/` — `PART.md` со стопом, `chunks/` с кусками, `answers/` для ответов, `segments.json`, `index.json`; `parts/INDEX.md` — сводка и фраза запуска;
- `tools/part.py` — очередь и проверка без дерева Mobius: подстановки, сущности, числа, теги, символы, латиница вне глоссария, основы терминов, все номера, объём перевода. Код 1 при любой ошибке. `done` проверяет файл, коммитит, пушит и печатает следующий, дальше с ошибками не пускает.

В пакет идут только куски, которые есть в чистом архиве Mobius. Наш текст из модов (12 кусков, 1 492 знака) туда не попадает. `html/admin` не берётся. Части не пересекаются: кусок переводится в первой части, где встретился, поэтому параллельные сессии не конфликтуют.

### Как забрать ответы

Ветки сессий сливаются в общую ветку пакета (части не пересекаются, конфликтов нет), дальше в L2Hub, по порядку:

```
python -X utf8 tools/ru_pages_cloud.py collect --pkg <папка пакета> --tm tools/ru_pages/tm_ct26_highfive.tsv --glossary-in docs/RU_GLOSSARY.md --glossary-out docs/RU_GLOSSARY.md
python -X utf8 tools/ru_pages.py build --tree <база> --list <все страницы> --tm tools/ru_pages/tm_ct26_highfive.tsv --out <страницы> --partial
python -X utf8 tools/ru_pages_check.py --tree <база + страницы> --list <страницы из build> --tm tools/ru_pages/tm_ct26_highfive.tsv --glossary docs/RU_GLOSSARY.md -v
```

`collect` принимает только файлы, прошедшие `part.py check`, кладёт ответы в память переводов и собирает таблицу «Имена и термины облачного перевода» в конец глоссария; прежняя таблица из `--glossary-in` выбрасывается, поэтому вход и выход могут быть одним файлом. Дальше он сам зовёт `tools/ru_pages_terms.py`: ответы частей переписывают память сырыми, и решения по терминам накладываются заново. Код 1 — не принят файл, правило сработало не столько раз, сколько записано, или у термина разнобой без решения в `CANON`. Решение — строка в `RULES` (правка памяти) и в `CANON` (строка глоссария), смотреть их глазами. `--partial` оставляет страницу с непереведённым куском английской целиком. В `--list` не должно быть `html/admin`. Без `-v` сверка печатает только первые 60 ошибок.

`build` не пишет страницу, которая после подстановки перевода совпала с английской байт в байт: в ней нечего переводить (подстановки, строки клиента `&$…;`, имя латиницей по глоссарию), а без русской сервер и так отдаёт английскую. На 2026-11-03 их 33: GM-шоп `html/merchant/50010-*.htm` (22, патч `0191`), шесть страниц доски и поиск предметов в `html/CommunityBoard` (`0193`), четыре в `html/mods/NpcView`.
